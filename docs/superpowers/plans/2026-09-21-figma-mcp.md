**Spec:** `docs/superpowers/specs/2026-09-21-figma-mcp-design.md`

- One new policy file: `examples/policies/figma.md`. Never vendor Figma skills (`examples/skills/figma/` is forbidden). Never edit `examples/skills/hallmark/SKILL.md` or `references/`.

- Match the language of each file you edit. Overlay `figma.md` is Indonesian (same register as `hallmark.md` / `superpowers.md`). Do not translate English files into Indonesian or vice versa.
- Upstream: [Figma remote MCP](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/). If commands drift, update CHECKLIST + MCP-SETUP + PROVIDER-MAPPING only. Do not paste long install commands into `AGENTS.md`.

- Figma is **not** a first-setup menu item. Checklist requires plugin/MCP per selected host (like Superpowers).
- Exceptions: spelling/punctuation in **existing** strings; README Markdown (`readme-style`); non-UI work; **this kit repo**. New copy, layout, color, type, or components → Figma.
- No automatic code → Figma sync. Do not skip `hallmark audit`. Do not make Hallmark optional.
- Working tree may contain unrelated uncommitted edits (for example `examples/skills/hallmark/README.md` or `docs/superpowers/plans/2026-09-21-claude-mem.md`). Apply only the replacements in this plan. Do not revert unrelated hunks. `git add` only the paths listed in each commit step.
